# myrobot

## 1. Overview
Gazebo를 사용한 시뮬레이션부터 실주행까지의 파이프라인을 가진 로봇청소기 시스템으로 Ros2 기반 Slam & Navigation을 사용하여 개발을 목표로함

## 2. Tech Stack
| Category | Stack |
| --- | --- |
| OS | Ubuntu 24.04 |
| Platform | Ros2 (Jazzy), Gazebo |
| Languages | C++, C, Python |
| Framework | Nav2, Qt, HAL |
